# External API verification log

The rule: no external API behavior is assumed from memory. Each entry records what was
checked against current documentation (with date) and what remains unverified.

| Dependency | Verified | Still unverified / to check before use |
|---|---|---|
| Internet Archive SPN2 | `POST https://web.archive.org/save` with `Authorization: LOW key:secret`, `Accept: application/json`, form `url=` returns `url`, `job_id`. `GET /save/status/<job_id>` returns `status` (pending/success/error); success has `timestamp`, `original_url`; error has `status_ext`, `message`. Capture URL `https://web.archive.org/web/<timestamp>/<original_url>`. Limits: 7 captures/min and 30k/day authenticated, 5 captures/URL/day; status kept ~1h. Source: "Save Page Now 2 Public API Docs" (Google Doc). (2026-10-26) | Not yet exercised live: the request shape is unit-tested with recorded responses only. Behaviour when a URL was archived within `if_not_archived_within` (default 1h) has not been observed. |
| Wayback CDX | `GET https://web.archive.org/cdx/search/cdx?url=<u>&output=json&limit=<n>&fl=timestamp,original,statuscode,digest` returns a JSON array where the first row is the header. Timestamps are `yyyyMMddHHmmss` in UTC. Unauthenticated. Shape unit-tested with recorded responses. (2026-10-27) | Rate limits unknown; the server occasionally returns 5xx under load. Not yet exercised live. |
| RDAP (IANA bootstrap) | `GET https://rdap.iana.org/domain/<domain>` with `follow_redirects=True` to the authoritative TLD RDAP server. Response per RFC 7483: `events[].eventAction` ∈ `registration` / `last changed` / `expiration` with `eventDate` ISO 8601; `entities[].roles[]` includes `registrar`; registrar vCard field `fn`. Some TLDs have no public RDAP → `404` → `NotConfigured`. Shape unit-tested with recorded responses. (2026-10-27) | TLD-specific response variance (which TLDs do/don't carry a registration date in events); rate limits; whether `follow_redirects=True` is sufficient for all redirect chains or if some registries need deeper redirect budgets. |
| tldextract 5.4 | `TLDExtract(suffix_list_urls=(), fallback_to_snapshot=True)` is fully offline — no live PSL fetch; shipped snapshot is used. `.domain + "." + .suffix` is the registrable domain. (2026-10-27) | Snapshot age: the bundled PSL will drift over time; a scheduled snapshot refresh in CI is deferred. |
| imagehash + Pillow (pHash) | `imagehash.phash(PIL.Image.open(io.BytesIO(bytes)))` is deterministic for identical bytes and captures structure, not color — solid-fill images hash the same regardless of color.
